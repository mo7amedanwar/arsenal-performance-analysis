# Arsenal Premier League Winning Analysis ⚽📊

A data analytics project analyzing how Arsenal F.C. won the Premier League using performance metrics and football analytics.

---

## 📊 Project Overview
This project analyzes match data to understand how Arsenal achieved a winning season through key performance indicators like attacking efficiency, defensive stability, and expected goals (xG).

---

## 🛠️ Tools Used
- Python (Pandas)
- Power BI
- Data Visualization
- Football Analytics

---

## 🔍 Key Insights
- Arsenal relied on high attacking efficiency rather than possession only
- Expected Goals (xG) was a strong indicator of performance
- Defensive consistency played a major role in winning matches
- Shot conversion rate had a big impact on results

---

## 🎯 Goal of the Project
To convert raw football data into meaningful insights that explain Arsenal’s Premier League winning season using data analytics.
